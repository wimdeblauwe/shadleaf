Site Header

Usage

Section titled “Usage”

<sl:site-header> is a header that lays out its content in a row. Whatever you put in it starts at the start of the line; the end slot goes to the end:

Across the top of the page it is the page’s banner landmark, on the page’s colour with a border below. It has no sticky option yet; the header scrolls with the page.

In the header layout

Section titled “In the header layout”

With a <sl:sidebar placement="header"> in it, it is the header layout’s header: from 768 px the sidebar is a row of links in it, and on a phone a menu button (<sl:sidebar-trigger>) opens the same navigation as a panel. It then goes first in <sl:sidebar-provider>, above <sl:sidebar-inset>. With variant="inset" on the sidebar the header lies on the sidebar’s colour without a border, and the page is a card below it.

The Application shell guide has the whole layout to copy.

As the page’s header

Section titled “As the page’s header”

At the top of <sl:sidebar-inset>, in the sidebar layout, it is the page’s header (shadcn’s sidebar-07): the trigger, a vertical separator, the breadcrumb, and the theme toggle at the end. Inside the main it is no landmark, and it has no border or colour of its own. The separator is a short line in the middle of the row there. The sidebar layout uses it this way.

Height

Section titled “Height”

The skins make it 3.5rem high (--site-header-height, set on .site-header): a minimum, so a breadcrumb that wraps on a narrow screen makes it taller.

Attributes

Section titled “Attributes”

sl:site-header declares no props; every attribute passes through.
