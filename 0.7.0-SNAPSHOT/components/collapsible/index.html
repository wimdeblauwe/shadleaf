Collapsible

Built from parts

Section titled “Built from parts”

A collapsible is <sl:collapsible> with an <sl:collapsible-trigger> and an <sl:collapsible-content>:

It is a <details> element with the trigger as its <summary>, so it needs no JavaScript: the browser opens and closes it, from the keyboard too, and tells a screen reader whether it is expanded. Two consequences for porting a shadcn/ui example:

  • The trigger comes first, and the content after it, both inside <sl:collapsible>. shadcn/ui’s examples can put the trigger anywhere in the collapsible, even after the content; a summary must be the first child.
  • Everything else goes in the trigger or the content. Text next to the trigger (shadcn’s “@peduarte starred 3 repositories” heading) can be part of the trigger.

open renders it open. As with the accordion, find-in-page and a link to an element inside open a closed collapsible on a match (Chrome and Edge 97, Firefox 148, Safari 26.2). It does not animate, as shadcn/ui’s does not.

Drawn as a button

Section titled “Drawn as a button”

The trigger is plain text by default. variant or size draws it as a button, with the button’s variants and sizes, where shadcn/ui writes <CollapsibleTrigger asChild><Button …>. An icon-only trigger (size="icon") needs an aria-label.

Disabled

Section titled “Disabled”

disabled keeps it closed (or open, with open): the trigger fades, leaves the tab order and ignores the pointer, and a closed disabled collapsible renders no content, so find-in-page cannot open it.

Left out

Section titled “Left out”
  • asChild on the trigger: variant and size draw it as a button; the element stays a summary.
  • open/onOpenChange state: open renders it open; the browser’s toggle event reports changes.
  • A trigger outside the collapsible, or after the content: a details element has its summary first.
  • Styling the trigger’s icon by state (shadcn’s group-data-[state=open]:rotate-90): the bundle has no utility classes. In your own CSS, .collapsible[open] > .collapsible-trigger svg { rotate: 90deg; } does it.

Attributes

Section titled “Attributes”

sl:collapsible

Section titled “sl:collapsible”
AttributeValuesDefaultDescription
openboolean—Render it open.
disabledboolean—It cannot be opened or closed: its trigger is out of the tab order and ignores the pointer, and closed it renders no content, so find-in-page cannot open it.

Every prop can also be set from an expression: th:open="${...}". Any other attribute passes through to the rendered element, and class is appended.

sl:collapsible-trigger

Section titled “sl:collapsible-trigger”
AttributeValuesDefaultDescription
variantdefault outline secondary ghost destructive link—Draw the trigger as a button of this variant, as on sl:button.
sizexs sm default lg icon icon-xs icon-sm icon-lg—Draw the trigger as a button of this size, as on sl:button. The icon sizes need an aria-label.

Every prop can also be set from an expression: th:variant="${...}". Any other attribute passes through to the rendered element, and class is appended. An aria-label or aria-labelledby is required when size is icon, icon-xs, icon-sm or icon-lg; rendering fails without one.

sl:collapsible-content

Section titled “sl:collapsible-content”

sl:collapsible-content declares no props; every attribute passes through.
