Only admins see the Admin link in the header (and in the phone panel, which is the same navigation): the layout wraps its menu item in sec:authorize="hasRole('ADMIN')". That only hides the link. What keeps everyone else out is the rule on the URL, .requestMatchers("/admin/**").hasRole("ADMIN") in SecurityConfiguration: a user without the role who types the address gets a 403.
