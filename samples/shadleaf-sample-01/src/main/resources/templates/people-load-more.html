The same people, read a Slice at a time: Spring Data asks for one row more than it shows to know whether there is a next slice, and never counts them all. Load more appends the next slice's rows with htmx and moves the focus to the first of them; the address follows (?page=…), so a reload shows the same rows. Without JavaScript, Load more is a link to that address, which the server renders with every slice up to it, and the browser scrolls to the first new row.
