4. Skin swap

This page uses the default skin. Run with --shadleaf.skin=flat for the second one: same markup, same tokens, different geometry, weight and focus ring.

5. Own the template

Copy templates/sl/components/button.html from the Shadleaf jar into the application's own src/main/resources/templates/sl/components/. The application's copy comes first on the classpath, props included, so it wins with no configuration. It no longer receives the library's fixes.

This sample keeps its copy in its test resources (see ButtonOverrideTest), so the page above still shows the library's button while the library is developed against it.

Application icons

An IconSource bean (see ShadleafSample01Application) reads src/main/resources/icons/*.svg before the bundled lucide icons. Its leaf.svg replaces lucide's leaf.
