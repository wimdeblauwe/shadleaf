Sorted and paged on the server by Spring Data JPA, from an in-memory H2 database. Each column header is a link to ?sort=…,asc (or desc when that column is sorted ascending already), each page to ?page=… and each size to ?size=…, keeping the other parameters. The controller's Pageable reads them, and the Page it gets back tells the table which column is sorted and the pagination which page it is on.

The controller adds the id as the last sort key, so people with the same number of orders keep one order and every person is on exactly one page. Roles are stored as their rank, so they sort Owner, Admin, Member, Guest.

The search filters on name and email. With htmx it searches while you type, and the headers, pages and sizes replace only the table; without JavaScript, Enter sends the form. Either way the order and the page size stay, and a search starts on the first page.
