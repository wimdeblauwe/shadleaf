A form validated on the server with Bean Validation. Submit it empty to see the errors. Each field has one th:field: the field gives its control the id the label points at, shows the binding's messages, and links description and messages to the control with aria-describedby. A message with a link in it (https://...) is rejected by the controller as a whole: that global error shows at the top of the form. The reference is read-only: it can be focused and copied, and it is posted with the form. Chat is a disabled option. The form with htmx is the same form, posted without a page load.
