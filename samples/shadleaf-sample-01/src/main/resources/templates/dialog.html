From the server, with htmx

Edit fetches the dialog into #modal-root, and <sl:dialog open> shows it. Save posts the form with htmx: with errors the form comes back with them and the dialog stays open; after a valid save the response header HX-Trigger: sl-dialog-close closes it and the row is updated.

Delete fetches an alert dialog the same way. Its Delete button sends hx-delete; the response closes the alert dialog with the same event, removes the row and moves focus to a message saying what happened. Cancel, which has the focus when it opens, sends nothing.

Invite member opens a sheet that is in the page. Its form posts with htmx and swaps itself: with errors the sheet stays open; after a valid invite an empty form comes back, the sheet closes and the new member is added to the table.
