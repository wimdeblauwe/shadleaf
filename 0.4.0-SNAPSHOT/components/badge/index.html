Badge

Variants

Section titled “Variants”

The same variants as the button.

With an icon

Section titled “With an icon”

Put an <sl:icon> in the icon-start or icon-end slot. It takes the badge’s colour and a 12 pixel size.

As a link

Section titled “As a link”

as="a" renders an anchor, for a badge that filters a list or opens a detail page. Only a linked badge reacts to hover and shows a focus ring; a plain badge is not interactive, so it does not pretend to be.

A badge is text, so a screen reader reads it where it stands. When a bare number or a single word would not make sense out of context, write the context into the text, or next to the badge.
