Icon

<sl:icon> inlines the SVG of a lucide icon into the page: no sprite, no extra request, and it works inside htmx swaps. It draws in currentColor, so it takes the colour of the text around it. An unknown name fails with the closest known ones.

Decorative or meaningful

Section titled “Decorative or meaningful”

Without a label an icon is decorative: it renders aria-hidden="true", which is right next to text or inside a labelled button. With a label it is announced as an image with that name.

Attributes

Section titled “Attributes”
AttributeValuesDefaultDescription
namestring—Name of the icon, e.g. trash. Lucide's names and aliases, plus any icons the application registers.
sizenumber—Width and height in pixels. Without it the icon is 24 pixels, or sized by the surrounding component (16 pixels inside a button).
stroke-widthnumber—Stroke width, overriding the icon's own (2 for lucide).
labelstring—Accessible name for an icon that carries meaning on its own. Without it the icon is decorative and hidden from assistive technology.

Every prop can also be set from an expression: th:name="${...}". Any other attribute passes through to the rendered element, and class is appended.
