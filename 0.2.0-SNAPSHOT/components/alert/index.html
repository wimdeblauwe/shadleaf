Alert

Built from parts

Section titled “Built from parts”

<sl:alert> holds an optional <sl:icon>, then <sl:alert-title> and <sl:alert-description>, as in shadcn/ui. The icon takes the alert’s colour and sits beside both. Use either part on its own.

Destructive

Section titled “Destructive”

Announcing an alert

Section titled “Announcing an alert”

An alert is not announced by itself. Most alerts are part of the page when it loads, and a screen reader reads them in order with everything else; announcing them too would interrupt the user for no reason.

When an alert appears later, for example in the response to an htmx request, add role="alert". A screen reader then reads it as soon as it is inserted. Like any other attribute, role passes through to the rendered element.

For a message that is not urgent, role="status" is announced when the user is idle instead of at once.
