Toggle Group

The items of a toggle group are toggles around radio buttons (type="single", the default: one item is on at a time) or checkboxes (type="multiple": any number). The form submits them as such inputs, and they work without JavaScript. In a single group the arrow keys move between the items and Tab leaves the group, as in any group of radio buttons; in a multiple group every item is a tab stop.

Name the group with aria-label, or with aria-labelledby pointing at its label. Give each item a value; an item that holds only an icon needs an aria-label.

Outline

Section titled “Outline”

In a form

Section titled “In a form”

Write th:field on the group, once. The items share it: Spring gives them the field’s name, numbers their ids (layout1, layout2, …) and checks the one whose value matches the field. Without a form object, name on the group gives the items their name. A single group with neither gets a generated name, so its items still exclude each other; give it a name when the form should submit it.

In a field set with th:field, the group takes the field set’s, and the legend labels it.

Multiple

Section titled “Multiple”

With type="multiple", bind a collection (a List, a Set, an array). Spring checks every item whose value is in it, and adds a hidden marker input, so a form with no item on clears the collection.

Sizes

Section titled “Sizes”

Spacing

Section titled “Spacing”

spacing sets the gap between the items, in Tailwind’s spacing steps: 2 (0.5rem) by default, 0 to join them into one control.

Invalid

Section titled “Invalid”

A field with errors marks every item aria-invalid="true".

Disabled

Section titled “Disabled”

With tooltips

Section titled “With tooltips”

Put an item in a tooltip. The group still joins the items, the tooltip shows on hover and when the keyboard focuses the item, and its text describes the item’s input. An icon-only item already has its aria-label: give the sl:tooltip mode="label", so a screen reader does not say it twice.

Every prop can also be set from an expression: th:type="${...}". Any other attribute passes through to the rendered element, and class is appended.
