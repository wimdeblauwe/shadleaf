Breadcrumb

Built from parts

Section titled “Built from parts”

A breadcrumb is shadcn/ui’s parts: a nav holding an ordered list of levels, with a separator between them. The last level is the page shown now.

<sl:breadcrumb-link> is a link: give it an href or th:href. <sl:breadcrumb-page> is plain text with aria-current="page". The list wraps onto a second line when there is no room, as on a phone.

In an application shell the breadcrumb goes in the page header, after the sidebar’s trigger and a vertical separator.

Collapsed levels

Section titled “Collapsed levels”

A long trail can leave levels out. An empty <sl:breadcrumb-ellipsis> stands for them; a screen reader says “More levels”.

With a menu

Section titled “With a menu”

Give the ellipsis the levels it stands for, as dropdown menu items, and it becomes a ghost icon button that opens a menu of them, as in shadcn’s example:

The button is named “Show more levels”; an aria-label replaces it, and any other attribute goes to the button too. The menu’s id is breadcrumb-more (the button’s breadcrumb-more-trigger): give a second breadcrumb with a menu on the same page another id. The menu behaves as every dropdown menu: arrow keys, Home, End and typeahead move through the levels, Enter follows one, Escape closes it and gives the focus back to the button.

Separator

Section titled “Separator”

The separator is a chevron that points to the next level: to the left on a right-to-left page (dir="rtl"). Content of its own replaces it, such as another icon; that content is not turned around.

Accessibility

Section titled “Accessibility”
  • The nav is named “Breadcrumb” (sl.breadcrumb.label); an aria-label of your own replaces it, which two breadcrumbs on one page need.
  • The separators are list items hidden from assistive technology, so a screen reader counts only the levels.
  • The page shown now has aria-current="page" and is not a link. shadcn’s adds role="link" and aria-disabled="true", which a screen reader announces as a link that goes nowhere.
  • The empty ellipsis reads “More levels”, where shadcn/ui hides it from screen readers.
  • In Windows’ high-contrast mode a focused link gets an outline, as the focus ring (a shadow) is gone there.

Messages

Section titled “Messages”
Key English

sl.breadcrumb.more More levels
sl.breadcrumb.more.trigger Show more levels

Left out

Section titled “Left out”

A breadcrumb built from the request’s path or from the sidebar’s menu, and structured data (BreadcrumbList) for search engines.

sl:breadcrumb-ellipsis

Section titled “sl:breadcrumb-ellipsis”
AttributeValuesDefaultDescription
idstring—With content: the menu's id, breadcrumb-more when not set (the button's is &lt;id&gt;-trigger); give a second breadcrumb on the page another one. Without content: the ellipsis's own id.

Every prop can also be set from an expression: th:id="${...}". Any other attribute passes through to the rendered element, and class is appended.

JavaScript

Section titled “JavaScript”

Only the ellipsis with a menu needs any: it is a dropdown menu, which needs Alpine and no plugin. Without it the button still opens the menu (the browser’s popover), without the arrow keys.
