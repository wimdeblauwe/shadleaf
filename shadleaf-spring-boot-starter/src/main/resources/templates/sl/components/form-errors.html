The errors of the form object the enclosing th:object selects, shown as a destructive alert: by default the errors that belong to the whole form rather than one field (global errors, from bindingResult.reject(...) or a class-level constraint); with show="all" the field errors too. One message as text, several as a list. It renders nothing while there are none. Content of its own replaces the messages, and always shows. Not announced and not focused by itself; it has an id (signup-errors for th:object="${signup}") and tabindex="-1", so autofocus, a link or a script can move focus to it. Which errors to list: the global errors only, or all of them, the global ones first and then every field's (each field keeps its own error too). Field messages are listed as they are, without the field's label, so write them to make sense on their own. The title above the messages. Defaults to the message sl.form-errors.title ("There is a problem"); use th:title for a message of your own. Heading level of the title. With it the title is a heading (role="heading" and aria-level) that screen reader users can jump to; without it, plain text.
