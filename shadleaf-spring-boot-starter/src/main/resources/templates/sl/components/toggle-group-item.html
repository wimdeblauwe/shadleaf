One item of a sl:toggle-group, drawn as a sl:toggle: a radio button in a single group, a checkbox in a multiple one. Give it a value; it takes the group's th:field or name, variant, size and disabled. The content is its label; give an item that holds only an icon an aria-label. Every attribute that is not a prop (value, checked, disabled, aria-label) passes through to the input, except class, which goes to the label around it. With th:field, the item is marked aria-invalid when its field has errors.
