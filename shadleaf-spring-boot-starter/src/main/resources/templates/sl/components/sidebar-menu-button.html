A link (or button) in a sl:sidebar-menu-item: an icon in the icon-start slot, then the label. Mark the current page with active, for instance th:active="${#slNav.current('/people')}". The label is cut off with an ellipsis when it does not fit; for two lines, put each in an element of its own (<strong>, <small>). Every attribute that is not a prop passes through (href, hx-*); class is appended to sidebar-menu-button. In a collapsible sl:sidebar-menu-item it is the item's summary, which opens and closes the group, with a chevron at the end; as, type and disabled do not apply there, and it takes no href. Element to render: an anchor (a) to a page, or a button for an action. The current one: the link gets aria-current="page", a button aria-current="true", and both the active look. Visual style: outline adds a background and a border. Height: sm for a dense list, lg for an entry with two lines, such as the application's name in the sl:sidebar-header. Submit behaviour of a button; defaults to button. Disable it. A disabled link loses its href and leaves the tab order. The label to show beside the button while the sidebar is collapsed to icons (collapsible="icon"), on hover and on keyboard focus; usually the same words as the label. Not shown while the sidebar is expanded or on a phone. It repeats the button's name, so it is hidden from assistive technology and describes nothing (sl:tooltip's mode="label"). [[${props.tooltip}]]
