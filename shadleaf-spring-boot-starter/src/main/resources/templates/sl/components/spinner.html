A spinning icon that says something is loading: a status (role="status") named "Loading" (the message sl.spinner.label; an aria-label of its own replaces it). It turns slower, not still, when the user asks for reduced motion. For a button that is busy, use sl:button loading instead. Width and height in pixels. Without it the spinner is 16 pixels, or sized by the surrounding component (as an icon in sl:empty-media).
