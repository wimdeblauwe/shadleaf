A modal dialog on the native dialog element: the page behind it is inert, Escape and a click outside close it, and focus returns to where it came from. Build it from sl:dialog-header (holding sl:dialog-title and sl:dialog-description), your content and sl:dialog-footer. A button opens it with commandfor set to the dialog's id and command="show-modal", and closes it with command="close"; an htmx response closes it with the sl-dialog-close event. The dialog's id, which the buttons that open and close it point at with commandfor. The title and description ids derive from it. Open the dialog as soon as it is on the page, for a dialog the server renders in answer to a request (an htmx swap, or a page shown after a redirect). Needs Alpine. A close button (an x) in the corner.
