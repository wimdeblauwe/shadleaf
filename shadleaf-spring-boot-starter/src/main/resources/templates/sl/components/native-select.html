The browser's own select, styled, with its option and optgroup elements as content. th:field marks the bound option. Every attribute that is not a prop passes through to the select, except class, which goes to the wrapper around it (for its width). With th:field, the select is marked aria-invalid when its field has errors. In a sl:field, it takes the field's th:field, id and aria-describedby. Height of the select. It replaces HTML's size attribute, which turns a select into a list box.
