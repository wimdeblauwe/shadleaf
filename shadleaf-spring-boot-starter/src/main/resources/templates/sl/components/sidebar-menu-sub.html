A list of links below a sl:sidebar-menu-button, indented along a line: a ul of sl:sidebar-menu-sub-items. In a collapsible sl:sidebar-menu-item it is what opens and closes. With collapsible of its own it opens and closes by a chevron beside the menu button, which stays a link to a page of its own. Hidden while the sidebar is collapsed to icons. Open and close it with a chevron at the end of the menu button (a summary, drawn as a sl:sidebar-menu-action), so the menu button stays a link. The chevron holds only an icon, so it needs an aria-label that names the sub-menu ("Playground's pages"); every other attribute goes to the ul. Render a collapsible sub-menu open, for instance when it holds the current page: th:open="${#slNav.current('/playground')}".
