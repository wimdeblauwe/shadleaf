The wrapper of an application shell with a sidebar: it holds sl:sidebar, and sl:sidebar-inset with the page's content (and the sl:sidebar-trigger), and it holds whether the sidebar is expanded or collapsed on a desktop. The server renders that state from the sl-sidebar-state cookie, which the browser writes when the user collapses or expands the sidebar (the trigger, or Ctrl/⌘+B), so every page starts in it without a jump. Below 768 px the sidebar is a panel the trigger opens instead, and the state does not apply. Needs Alpine for the trigger and the shortcut; without JavaScript the sidebar stays as the server rendered it. The state to render, whatever the cookie says: for an application that keeps the choice itself, such as in the user's settings. Without it, the cookie decides. The state before the user chose one (no cookie yet).
