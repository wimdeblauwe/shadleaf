A modal dialog that interrupts the user with something important and waits for an answer, such as a confirmation before deleting. Built on the native dialog element with role="alertdialog": a click outside does not close it, Escape does. Build it from sl:alert-dialog-header (with an optional sl:alert-dialog-media, sl:alert-dialog-title and sl:alert-dialog-description) and sl:alert-dialog-footer holding sl:alert-dialog-cancel, which takes the focus when the dialog opens, and the action, a sl:button. A button opens it with commandfor set to its id and command="show-modal"; an htmx response closes it with the sl-dialog-close event. The dialog's id, which the button that opens it points at with commandfor. The title and description ids derive from it. Size of the dialog. sm is narrower, with the header centred and the footer's two buttons side by side. Open the dialog as soon as it is on the page, for a dialog the server renders in answer to a request (an htmx swap). Needs Alpine.
