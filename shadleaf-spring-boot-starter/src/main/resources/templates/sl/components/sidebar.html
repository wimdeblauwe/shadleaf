The application's navigation, inside sl:sidebar-provider. One element serves both widths: from 768 px up it is a column beside the page, which the trigger collapses and expands; below that it is a panel over the page, which the trigger opens. It is a nav named "Main" (sl.sidebar.label; an aria-label replaces it) and a popover: the browser opens the panel in the top layer and closes it on Escape or a click outside. On a phone, Alpine moves the focus into the open panel and makes the rest of the page inert, and closes it when a link in it is followed. It holds sl:sidebar-header, sl:sidebar-content (groups of menus) and sl:sidebar-footer. The id the trigger points at (sl:sidebar-trigger's for). The edge it sits on: the start of a line (the left, or the right on a right-to-left page) or the end. How it collapses on a desktop: offcanvas moves it out of view entirely. Collapsing to icons comes later.
