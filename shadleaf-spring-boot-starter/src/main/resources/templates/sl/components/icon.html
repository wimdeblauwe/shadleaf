Inlines the SVG of an icon: the bundled lucide icons, or the application's own through an IconSource bean. An unknown name fails with the closest known ones. Name of the icon, e.g. trash. Lucide's names and aliases, plus any icons the application registers. Width and height in pixels. Without it the icon is 24 pixels, or sized by the surrounding component (16 pixels inside a button). Stroke width, overriding the icon's own (2 for lucide). Accessible name for an icon that carries meaning on its own. Without it the icon is decorative and hidden from assistive technology.
