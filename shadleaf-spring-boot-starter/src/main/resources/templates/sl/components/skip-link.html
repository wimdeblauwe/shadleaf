A link past the navigation to the page's content, for keyboard users: put it first in the body. Hidden until it has the focus (the first Tab on the page), then drawn at the top of the page. Its text is "Skip to main content" (the message sl.skip-link), which content of its own replaces. The target should be able to take the focus: sl:sidebar-inset is id="main" with tabindex="-1", so the default target works with it. The id of the element it skips to, usually the main.
