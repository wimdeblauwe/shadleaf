The input of a sl:input-group: a sl:input without a border of its own, as the group draws it. Every attribute that is not a prop (th:field, name, placeholder, required, hx-*) passes through; class is appended to input. With th:field, the input is marked aria-invalid when its field has errors. In a sl:field, it takes the field's th:field, id and aria-describedby. Type of the input.
