What opens and closes a sl:dropdown-menu: by default a sl:button, or with as a sidebar part (shadcn's <DropdownMenuTrigger asChild>). It renders that part with popovertarget set to the menu, which it names. Arrow down opens the menu on its first item, arrow up on its last. Its icon-start and icon-end slots go to the part's; any other attribute passes through to it. The part to render: a sl:button, a sl:sidebar-menu-button (a team switcher or user menu in a sl:sidebar-menu-item), or a sl:sidebar-menu-action (a "More" beside a menu button, which needs an aria-label). Visual style, as on sl:button, or default and outline as on sl:sidebar-menu-button. Not for a sidebar menu action. Size, as on sl:button (the icon sizes need an aria-label), or sm, default and lg as on sl:sidebar-menu-button. Not for a sidebar menu action. With as="sidebar-menu-button": the label shown beside it while the sidebar is collapsed to icons, as on sl:sidebar-menu-button. Never shown while the menu is open. With as="sidebar-menu-action": from 768 px, show it only while the pointer is over its item, the focus is in it, or the menu is open.
