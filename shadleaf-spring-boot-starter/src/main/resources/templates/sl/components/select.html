A select drawn like shadcn/ui's: a real select with sl:select-item, sl:select-group and sl:select-separator as content, so th:field, submitting and the keyboard work as for any select. Where the browser supports the customizable select (appearance: base-select) it draws the list itself; elsewhere slSelect puts a list box in its place once Alpine runs. Every attribute that is not a prop passes through to the select, except class, which goes to the wrapper around it. In a sl:field, it takes the field's th:field, id and aria-describedby. Height of the select. Text shown while no option is chosen: a first option with an empty value, hidden from the list. A required select with it selected is invalid.
