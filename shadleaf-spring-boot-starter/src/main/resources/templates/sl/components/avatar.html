A picture of a person: an sl:avatar-image, and an sl:avatar-fallback (initials) shown instead while the image has no src, is loading or fails to load. Decorative unless it has a label, as an avatar usually sits next to the person's name. Size of the avatar. The person's name, for an avatar with no name next to it. It is then announced as an image with that name; without it the avatar is hidden from assistive technology.
