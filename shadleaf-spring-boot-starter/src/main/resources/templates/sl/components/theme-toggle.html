Switches the page between the light and the dark theme, and remembers the choice in the browser under the key the theme script (sl/layout :: theme-script) reads before the first paint, so the next page starts in it. By default an icon button opening a menu with Light, Dark and System; with as="button" one button that switches between light and dark. Its icon shows the theme the page is in. Needs Alpine; without JavaScript it is not shown. Every attribute that is not a prop passes through to the button. menu: a menu with Light, Dark and System (menuitemradios). button: one toggle button for dark mode (aria-pressed), which cannot go back to following the system. The menu's id (its button gets the id with -trigger added). Two menus on a page need different ids. With as="button" it is the button's id, rendered only when set. Visual style of the button, as on sl:button. Size of the button: one of sl:button's icon sizes. The side of the button the menu opens on, as on sl:dropdown-menu-content. How the menu lines up with the button along that side, as on sl:dropdown-menu-content: end lines up the end edges.
