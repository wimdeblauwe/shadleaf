A checkbox: the browser's own, styled. Every attribute that is not a prop (th:field, name, value, checked, required) passes through to the input, except class, which goes to the wrapper that holds the check mark. With th:field, Spring numbers the id (terms1), so put the checkbox inside its label, in a sl:field (which gives it the field's name as id), or give it an explicit id; the checkbox is marked aria-invalid when its field has errors. A checkbox in the indeterminate state (neither checked nor unchecked: some of a group selected) shows a minus. Start in the indeterminate state. HTML has no attribute for it, only the DOM property indeterminate: this renders data-indeterminate, from which Shadleaf's script sets the property when the page loads (or htmx swaps the checkbox in). A click clears it, as it does on every checkbox. A script can set the property on any checkbox; the minus follows it.
