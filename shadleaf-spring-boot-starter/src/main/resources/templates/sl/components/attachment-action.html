A button in sl:attachment-actions, to remove, retry or download the file: a sl:button, ghost and an extra small icon by default. Give it an aria-label that names the file ("Remove report.pdf"). Any other attribute passes through to the sl:button (href, type, disabled, hx-*). Visual style of the button, as on sl:button. Size of the button, as on sl:button. The icon sizes are square, for a button that holds only an icon, and need an aria-label. Element to render: a button, or an anchor (a) to download or open the file.
