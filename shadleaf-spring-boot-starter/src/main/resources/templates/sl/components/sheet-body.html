The content of a sl:sheet between its header and footer, which scrolls by itself so the header and footer stay in view. Its content has the id <id>-body (edit-body), the target for htmx: a request from outside that targets it opens the sheet at once and shows a spinner until the answer is swapped in; closing aborts a request still running. Left empty, it is emptied again when the sheet closes, so it never shows the previous content. When a request fails, the error shows in the sheet, or, for the request that opened it, as a toast (see load-error). Needs Alpine. What happens when the request that opened the sheet fails: toast closes it and shows the error as a toast (shown in the sheet when the page has no sl:toaster); inline keeps it open with the error in it. A failed request from inside (a form) always shows the error in the sheet, so nothing typed is lost.
