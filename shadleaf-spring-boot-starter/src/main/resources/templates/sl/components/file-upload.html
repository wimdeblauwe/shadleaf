A drop zone to pick files with, and the list of the files picked. Shadleaf's own: shadcn/ui has none. A visually hidden <input type="file"> holds the files and is submitted with the form, so put th:field on the component (a MultipartFile, or with multiple a List<MultipartFile>) and give the form enctype="multipart/form-data". Every attribute that is not a prop goes to the input (th:field, name, id, required, disabled, aria-*, hx-*); class is appended to the component. In a sl:field, the input takes the field's th:field, id and aria-describedby. With JavaScript, files can be dropped too, each picked file shows as an sl:attachment with a remove button, and a file that does not match accept or is larger than max-size shows as an error. Without it, the Browse button still picks files. The server checks the files anyway. Take more than one file. Picking or dropping files adds them to the ones already there. The file types to take, as the input's accept: extensions (.pdf), MIME types (application/pdf) or image/*, separated by commas. A dropped file of another type is not added. The largest file to take, as Spring Boot writes sizes: 10MB, 500KB. A larger file is not added. Makes the title a heading of this level (role="heading"). The text of the Browse button. Defaults to "Browse files", or "Browse" without multiple.
