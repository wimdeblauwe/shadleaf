One series of a sl:chart, drawn as a filled area under a line through the rows. Draws no element of its own on the page: the chart reads it. The property of the rows that holds this series' numbers (desktop): letters, digits, _ and -, as it also names the colour property --color-<key>. The series' name in the tooltip and the legend, typically a message (th:label="#{visitors.desktop}"). Defaults to the key. Its colour, any CSS colour (var(--chart-3), #2563eb). Defaults to the chart tokens in turn: the first series var(--chart-1), the second var(--chart-2), and so on (after the fifth, again from the first). A different colour in the dark theme; color is then the light one (the two go into light-dark()). How the line runs between the points: smooth (natural, monotone), straight (linear) or in steps. Stack this series on the others with the same stack id (any name, such as a). The opacity of the fill, from 0 to 1.
