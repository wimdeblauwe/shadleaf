A file or an image attached to something: a message, a form, a record. Holds an sl:attachment-media, an sl:attachment-content (title and description), optional sl:attachment-actions and an optional sl:attachment-trigger that makes the whole card open a link or a dialog. Purely presentational: the server renders its state. Say the state in the description too ("Uploading · 64%", "Upload failed"), so it is not told by colour alone. Where the file is in its upload: idle (picked, not sent yet) draws a dashed border, uploading and processing shimmer the title and mark the attachment busy (aria-busy), error turns it destructive. done is a file that is there. Size of the attachment. vertical puts the media above the content, for an image. Fill the width of the container, for a list of attachments (shadcn's w-full class). Without it the attachment is as wide as its content.
