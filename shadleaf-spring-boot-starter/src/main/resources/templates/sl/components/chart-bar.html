One series of a sl:chart, drawn as bars: one per row. Draws no element of its own on the page: the chart reads it. The property of the rows that holds this series' numbers (desktop): letters, digits, _ and -, as it also names the colour property --color-<key>. The series' name in the tooltip and the legend, typically a message (th:label="#{visitors.desktop}"). Defaults to the key. Its colour, any CSS colour (var(--chart-3), #2563eb). Defaults to the chart tokens in turn: the first series var(--chart-1), the second var(--chart-2), and so on (after the fifth, again from the first). A different colour in the dark theme; color is then the light one (the two go into light-dark()). The bars' corner radius in pixels: 4 for every corner, or four numbers (top-left, top-right, bottom-right, bottom-left), as 4,4,0,0 for the top bar of a stack. Stack this series on the others with the same stack id (any name, such as a) instead of drawing them side by side.
