A dialog that slides in from an edge of the screen, for content that complements the page: filters, settings, details. Built on the native dialog element, like sl:dialog: the page behind it is inert, Escape and a click outside close it, and focus returns to where it came from. Build it from sl:sheet-header (holding sl:sheet-title and sl:sheet-description), your content and sl:sheet-footer. A button opens it with commandfor set to the sheet's id and command="show-modal". The sheet's id, which the buttons that open and close it point at with commandfor. The title and description ids derive from it. The edge it slides in from. right and left are the end and the start of a line: on a right-to-left page a right sheet opens on the left. Open the sheet as soon as it is on the page, for a sheet the server renders in answer to a request (an htmx swap). Needs Alpine. A close button (an x) in the corner.
