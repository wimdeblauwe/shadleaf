A link (or button) in a sl:sidebar-menu-sub-item. Mark the current page with active, for instance th:active="${#slNav.current('/settings/billing')}". An optional icon goes in the icon-start slot; the label is cut off with an ellipsis when it does not fit. Every attribute that is not a prop passes through (href, hx-*); class is appended to sidebar-menu-sub-button. Element to render: an anchor (a) to a page, or a button for an action. The current one: the link gets aria-current="page", a button aria-current="true", and both the active look. Text size: sm for a denser list. Submit behaviour of a button; defaults to button. Disable it. A disabled link loses its href and leaves the tab order.
