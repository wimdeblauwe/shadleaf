The value axis of a sl:chart, at the start side (the left, or the right under dir="rtl"), without tick or axis lines. A chart can leave it out and show the values in the tooltip. Draws no element of its own on the page: the chart reads it. How the ticks are written, as on sl:chart-x-axis: compact (1.2K) and currency suit a value axis. The ISO 4217 code (EUR) for format="currency". Space in pixels between the ticks and the plot. How many ticks Recharts aims for.
