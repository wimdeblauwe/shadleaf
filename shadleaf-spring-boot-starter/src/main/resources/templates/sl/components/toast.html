One toast in a sl:toaster: a title, an optional description and a close button. The server renders it for a message that has to show when the page loads, such as a flash attribute after a redirect, or in an out-of-band swap. Content of its own replaces the description. A toast goes away by itself, so it must never hold the only way to do something. What happened, in a few words: "Member deleted". More about it, under the title. The kind of message, shown by its icon: none, a check, an i, a warning triangle or an x. A screen reader announces an error at once, interrupting what it reads; the others when it is done. How long this toast shows, in milliseconds, instead of the toaster's duration. 0 keeps it until it is closed.
