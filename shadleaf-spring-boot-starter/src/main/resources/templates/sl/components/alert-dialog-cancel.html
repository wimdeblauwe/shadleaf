The button that closes a sl:alert-dialog without doing anything, in its sl:alert-dialog-footer. It takes the focus when the dialog opens, so Enter never confirms by accident. Its text defaults to "Cancel" (sl.alert-dialog.cancel); content of its own replaces it. Any other attribute passes through to the sl:button. Visual style of the button, as on sl:button. Size of the button, as on sl:button. Cancel
