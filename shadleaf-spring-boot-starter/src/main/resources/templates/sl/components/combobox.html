A text input that filters a list of options as you type. Like sl:select, it is a real select with sl:combobox-item, sl:combobox-group and sl:combobox-separator as content, so th:field binds it (a collection with multiple) and the form submits it. Once Alpine runs, slCombobox hides the select and puts an input and a list box in its place; without it, the select is drawn like sl:native-select. Every attribute that is not a prop passes through to the select, except class, which goes to the wrapper around it. In a sl:field, it takes the field's th:field, id and aria-describedby. The input's text while nothing is chosen. For a single value also the text of a first option with an empty value, hidden from the list: a required combobox with it chosen is invalid. Choose any number of options, shown as chips before the input. The select is a select multiple, so th:field binds a collection. A button that clears the choice, in place of the chevron while there is one. The chevron button that opens and closes the list. A multiple combobox has none. Highlight the first match while typing, so Enter chooses it. The text shown when no option matches. By default "No items found." Ask the server for the options as you type: a GET to this URL with the text as q, answered with the HTML of sl:combobox-items (and groups and separators), which replace the options that are not chosen. Needs JavaScript; without it, only the options in the page can be chosen.
