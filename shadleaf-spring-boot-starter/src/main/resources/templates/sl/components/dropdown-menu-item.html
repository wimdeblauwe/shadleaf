An action in a sl:dropdown-menu-content: a button, or with as="a" a link. Every attribute that is not a prop (hx-*, href, commandfor, form) passes through, and the menu closes once the item is chosen. Element to render: a button, or an anchor (a) for navigation. destructive for an item that deletes something. Submit behaviour of a button item. Defaults to button; submit submits the form it is in (or names with form). Indent the item to line up with items that start with an icon. Disable the item. The arrow keys skip it; a disabled link loses its href.
