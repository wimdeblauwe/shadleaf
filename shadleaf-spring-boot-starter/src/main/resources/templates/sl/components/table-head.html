A header cell (th) of a sl:table. With sort its label is a link that sorts the table by that property on the server: ascending, or descending when it is sorted ascending already. The link keeps the request's other parameters (filters, page size) and goes back to the first page. The sorted column gets aria-sort and an arrow. A plain th works too, for a header that does neither. The property to sort by, as the controller's Sort names it (name, address.city). Only the first key of the current order is shown.
