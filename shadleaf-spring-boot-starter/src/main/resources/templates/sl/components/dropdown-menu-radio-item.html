One of a set of choices in a sl:dropdown-menu-radio-group, with a check mark on the chosen one (role="menuitemradio"), such as the sort order of a list. The server marks the chosen one checked: each item is a link (?sort=name) or a request, and the page or fragment that comes back shows the new choice. Give it its text as content ([[${...}]]), not with th:text, which would replace the check mark too. Otherwise as sl:dropdown-menu-item. Whether this is the chosen item (aria-checked). Element to render: a button, or an anchor (a). Submit behaviour of a button item. Indent the item to line up with items that start with an icon. Disable the item. The arrow keys skip it.
