An item in a sl:dropdown-menu-content that shows an on/off state with a check mark (role="menuitemcheckbox"), such as a filter or a view setting. The state comes from the server: choosing the item does what its attributes say (a link to ?archived=true, an hx-post), and the page or fragment that comes back shows the new state. Give it its text as content ([[${...}]]), not with th:text, which would replace the check mark too. Otherwise as sl:dropdown-menu-item. Whether the setting is on (aria-checked). Element to render: a button, or an anchor (a). Submit behaviour of a button item. Indent the item to line up with items that start with an icon. Disable the item. The arrow keys skip it.
