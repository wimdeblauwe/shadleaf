One radio button in sl:radio-group: the browser's own, styled. Give it a value and the group's name, or th:field with a value or th:value; Spring then numbers the ids (plan1, plan2), so put the item inside its label. In a sl:field-set with th:field, the items take its field. Every attribute that is not a prop passes through; class is appended to radio-group-item. With th:field, the item is marked aria-invalid when its field has errors.
