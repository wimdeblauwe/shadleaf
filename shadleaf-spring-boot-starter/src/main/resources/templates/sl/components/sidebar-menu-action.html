An icon button at the end of a sl:sidebar-menu-item, beside its sl:sidebar-menu-button: a second action for that entry, such as "More" or "Remove from favourites". It holds only an icon, so it needs an aria-label that names the entry too ("More for Design Engineering"). Every other attribute passes through. Element to render: a button, or an anchor (a) to a page. Submit behaviour of the button; defaults to button. From 768 px, show it only while the pointer is over the item, the focus is in it, or its menu is open (aria-expanded="true"). Always shown on a phone.
