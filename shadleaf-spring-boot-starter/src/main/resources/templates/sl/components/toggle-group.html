A row of sl:toggle-group-items, of which one (type="single", radio buttons) or several (type="multiple", checkboxes) can be on. The items submit, bind and work as those inputs, without JavaScript. Name the group with aria-label or aria-labelledby. Give it the th:field (or the name) its items share, or put it in a sl:field-set with th:field; each item then only needs a value. Every other attribute that is not a prop passes through to the group. single: one item is on at a time, as radio buttons (the arrow keys move between them). multiple: any number, as checkboxes. Visual style of the items. Size of the items. The gap between the items, in Tailwind's spacing steps (2 is 0.5rem). 0 joins them into one control. Put the items on a row, or in a column. The name every item submits under, for a group without th:field. Disable every item.
