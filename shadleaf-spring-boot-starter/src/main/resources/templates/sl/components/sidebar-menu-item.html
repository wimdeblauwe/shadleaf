One entry of a sl:sidebar-menu: an li holding a sl:sidebar-menu-button, and optionally a sl:sidebar-menu-badge or a sl:sidebar-menu-action beside it. With a badge, the button is described by it (aria-describedby), so a screen reader says "Inbox, link, 12". With collapsible it is a group of links that opens and closes: the menu button is what the user clicks, followed by a sl:sidebar-menu-sub. The item's id. Its badge gets <id>-badge; without an id, each render generates one (sl-sidebar-menu-item- and eight random characters). Make it a group that opens and closes, on the browser's details element (no JavaScript needed): its sl:sidebar-menu-button becomes the summary, with a chevron, and its sl:sidebar-menu-sub the content. Collapsed to icons, a click on the button expands the sidebar and opens the group. It takes no badge or action: the browser would hide them with the sub-menu. Render a collapsible item open, for instance when it holds the current page: th:open="${#slNav.current('/settings')}".
