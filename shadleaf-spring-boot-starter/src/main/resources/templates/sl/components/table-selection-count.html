How many rows of a sl:table are selected: "2 of 20 selected" (the message sl.table.selection.count), kept up to date in the browser as rows are checked, as rows are replaced (an htmx swap) and after a form reset. Place it anywhere, e.g. at the start of the table's footer as shadcn/ui's data table does. It is not a live region: a click on sl:table-select-all announces the count, a row's checkbox announces its own state. Empty and hidden until Alpine starts. The id of the table whose rows it counts (sl:table puts its id on the table).
