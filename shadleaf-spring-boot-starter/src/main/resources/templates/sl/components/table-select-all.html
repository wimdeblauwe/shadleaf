A checkbox for a header cell of a sl:table that selects every row on the page. The rows are the application's own checkboxes (a sl:checkbox with name="ids" and th:value="${person.id}") in the cells of the table's body; they submit without JavaScript. This one is checked when every row is, indeterminate when some are, and checks or unchecks them all when clicked; it is named "Select all rows on this page" (the message sl.table.select-all) unless it gets an aria-label. It needs JavaScript, so it stays hidden until Alpine starts. It fires sl-table-selection-change on the table ({selected, total}), which sl:table-selection-count shows. It submits nothing itself (no name); other attributes go to its input, class to its wrapper. The name of the row checkboxes, when the body has checkboxes of another kind too. Without it, every checkbox in a body cell is a row.
