Panels of content shown one at a time, chosen from a row of tabs. Holds a sl:tabs-list of sl:tabs-triggers and a sl:tabs-content per tab. The server renders the active tab's panel and hides the others, so the page is right before any script runs; Alpine adds switching in the browser and the keyboard (the ARIA tabs pattern). Give the triggers an href and the tabs work without JavaScript too. The id of the tabs. The ids of the triggers and panels derive from it (settings-account-trigger, settings-account-content). The tab of the trigger and panel that are active when the page renders, e.g. from a request parameter: th:active="${tab}". vertical puts the tabs in a column next to the panels, and the up and down arrow keys move between them. automatic: a tab shows its panel as soon as the arrow keys reach it. manual: the arrow keys only move the focus, and Enter or Space shows the panel; for panels that are slow to show, such as ones loaded with htmx.
