A count at the end of a sl:sidebar-menu-button, inside the same sl:sidebar-menu-item. The button is described by it, so a screen reader says the count after the link's name ("Inbox, link, 12"); the badge gets its id from the item (<item id>-badge). Clicks go through it to the button.
