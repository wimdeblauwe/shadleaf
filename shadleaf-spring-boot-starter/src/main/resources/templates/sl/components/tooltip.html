A short text that shows while the pointer rests on an element or the keyboard focuses it, on the browser's Popover API. The first element inside is the trigger, any focusable element (a sl:button, a link); the sl:tooltip-content after it describes it (aria-describedby). Escape hides it. Needs Alpine. What the text is to a screen reader: description adds it to the trigger as a description; label is for a text that repeats the trigger's name, such as an icon button's aria-label: it is hidden from assistive technology and describes nothing, so the name is not said twice. How long the pointer rests on the trigger before the tooltip shows, in milliseconds. Keyboard focus shows it at once, and so does moving to another trigger right after a tooltip hid.
