An input with text, icons or buttons inside its border: one sl:input-group-input or sl:input-group-textarea, and sl:input-group-addons around it. Put the addons after the control in the markup, so the control comes first in the tab order and is read first; align on the addon places it. The group draws the control's focus ring, error and disabled look. In a sl:field, the control takes the field's th:field, id and aria-describedby.
