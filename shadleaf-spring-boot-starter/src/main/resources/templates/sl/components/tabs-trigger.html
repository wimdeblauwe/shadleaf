A tab in a sl:tabs-list, which shows the sl:tabs-content with the same tab. A button, or with an href a link to the page with this tab active: without JavaScript the link loads it, with Alpine the tab switches in place and the address follows. Which tab this is: the tab of its sl:tabs-content, and the value sl:tabs' active names. Part of the ids, so letters, digits and dashes. The tab cannot be chosen; the arrow keys skip it. A disabled link loses its href.
