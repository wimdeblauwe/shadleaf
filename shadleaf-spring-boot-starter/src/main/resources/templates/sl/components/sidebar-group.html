A section of the sl:sidebar's links: an optional sl:sidebar-group-label and sl:sidebar-group-action, then sl:sidebar-group-content with a sl:sidebar-menu. With a label it is a group named by that label (role="group", aria-labelledby), so a screen reader says "Platform, group" when the focus moves into it; without one it is a plain div. The group's id. Its label gets <id>-label; without an id, each render generates one (sl-sidebar-group- and eight random characters). Show it only in the phone panel: from 768 px it is left out (display: none), so a header row or a sidebar stays short.
