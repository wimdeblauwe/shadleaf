A styled table. Write the plain table elements inside it (caption, thead, tbody, tfoot, tr, th, td), with th:each on a row; there is no component per row or cell. Use sl:table-head for a header cell that sorts or aligns, and sl:table-empty for the row that says nothing was found. A colgroup per group of columns draws a line between the groups. The table scrolls sideways inside its own container when it is wider than the page. Attributes go to the table. The Spring Data Page or Slice the table shows. Its Sort tells every sl:table-head inside how the rows are sorted now. Without it, the headers read the order from the request's sort parameter. The @Qualifier of the controller's Pageable, for a second table on the page: its sort links use members_sort instead of sort. Pin the first cell of every row to the start edge, so it stays in view when a wide table scrolls sideways. It gets the page's --background (set --sl-table-bg on the table when it sits on something else, such as var(--card)), and an edge line appears once the table has scrolled. The density of the table. sm has smaller cells and text, for a table of many rows of figures or one meant for paper; the header, body, footer, caption, sort links and sl:table-empty row follow it.
