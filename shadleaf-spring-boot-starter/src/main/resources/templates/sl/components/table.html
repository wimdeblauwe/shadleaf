A table in shadcn/ui's look. Write the plain table elements inside it (caption, thead, tbody, tfoot, tr, th, td), with th:each on a row; there is no component per row or cell. Use sl:table-head for a header cell that sorts or aligns, and sl:table-empty for the row that says nothing was found. The table scrolls sideways inside its own container when it is wider than the page. Attributes go to the table. The Spring Data Page or Slice the table shows. Its Sort tells every sl:table-head inside how the rows are sorted now. Without it, the headers read the order from the request's sort parameter. The @Qualifier of the controller's Pageable, for a second table on the page: its sort links use members_sort instead of sort.
