The tooltip of a sl:chart: on hover, or with the arrow keys once the chart has the focus, it shows the category and every series' label and value. Draws no element of its own on the page: the chart reads it. The mark before each series' label, in its colour. Highlight the hovered category (a band behind bars, a line over lines and areas). Leave out the label at the top (the category). Leave out the marks before the series' labels. The property of the rows to take the label from instead of the axis category: a series key gives that series' label, any other property its value in the hovered row, such as a date the server formatted. How the label is written, as the ticks of sl:chart-x-axis (month, date, ...). Without one, as it is. How the values are written: number in the page's language, or currency, percent, ... The ISO 4217 code (EUR) for a currency format.
