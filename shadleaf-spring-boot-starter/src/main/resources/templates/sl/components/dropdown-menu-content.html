The menu itself, inside sl:dropdown-menu: a popover next to its trigger, in the top layer, holding the items, labels, groups and separators. It flips to the other side when there is no room. The side of the trigger it opens on. right and left are the end and the start of a line: on a right-to-left page a right menu opens on the left. How it lines up with the trigger along that side: start lines up the start edges.
