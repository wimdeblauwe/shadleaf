Stands for the levels a long trail leaves out. Without content it is an ellipsis, read as "More levels" (the message sl.breadcrumb.more). With content, the sl:dropdown-menu-items of those levels (as="a"), it is a ghost icon button named "Show more levels" (sl.breadcrumb.more.trigger; an aria-label replaces it) that opens a sl:dropdown-menu of them; any other attribute then goes to the button. With content: the menu's id, breadcrumb-more when not set (the button's is <id>-trigger); give a second breadcrumb on the page another one. Without content: the ellipsis's own id. More levels
