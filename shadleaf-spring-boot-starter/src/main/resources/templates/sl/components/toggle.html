A button that is on or off: a checkbox drawn as a button, so it submits, binds and works as one without JavaScript, and a screen reader announces it as checked or not. The content (text, icons) is its label; give a toggle that holds only an icon an aria-label. Every attribute that is not a prop (th:field, name, value, checked, disabled, aria-label, x-*) passes through to the input, except class, which goes to the label around it, and th:text and th:utext, which set the label. th:field on a boolean works as on a checkbox; the toggle is marked aria-invalid when its field has errors. Visual style of the toggle. Size of the toggle.
