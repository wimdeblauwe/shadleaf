A button showing the chosen date that opens a sl:calendar in a popover. Its value lives in the calendar's date inputs, so th:field binds it and the form submits ISO dates. Every attribute that is not a prop goes to the sl:calendar inside, except class, which stays on the date picker: the calendar's props (caption-layout, number-of-months, disabled-dates, ...) and, for a single date, the attributes of its input (th:field, name, required, min, max). In a sl:field, the input takes the field's th:field, id and aria-describedby, and the button is named by the field's label. For a range, give it two sl:input type="date"s as content, the start and the end, and an aria-label. A pick closes the popover; for a range the second pick does. Needs JavaScript (slDatePicker). The button's text while no date is chosen. By default "Pick a date". How the button shows the date, in the page's locale: as Intl.DateTimeFormat's dateStyle and Java's FormatStyle (10/23/26, Oct 23, 2026, October 23, 2026, Friday, October 23, 2026). The popover's id, which the button points at with popovertarget. By default a generated one (sl-date-picker- and eight random characters).
