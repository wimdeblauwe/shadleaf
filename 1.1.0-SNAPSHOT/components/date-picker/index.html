Date Picker

A popover with a calendar

Section titled “A popover with a calendar”

A date picker is a button in a popover with a calendar: the button shows the chosen date, and a pick closes the popover. <sl:date-picker> is that composition as one component, with the glue in the slDatePicker Alpine component.

The value lives in the calendar’s date inputs, so th:field binds a date picker as it binds a calendar, and the form submits ISO dates (2026-10-23). The LocalDate fields note applies here too.

Every attribute that is not a prop goes to the calendar inside. class is the exception: it stays on the date picker. So the calendar’s props work on the date picker (caption-layout, number-of-months, disabled-dates, …), and so do its input’s attributes (th:field, name, required, min, max, disabled, hx-*).

The button’s text

Section titled “The button’s text”

The button shows the chosen date, or placeholder (“Pick a date”) while there is none.

  • On the server, the date is formatted in the page’s locale (Spring’s LocaleResolver). That is what shows before JavaScript runs.
  • In the browser, slDatePicker formats it again with Intl, for the same locale, when it starts and after every change. Java and Intl both use the CLDR’s patterns, so the two texts agree.

format picks the style, as Intl.DateTimeFormat’s dateStyle and Java’s FormatStyle:

format en-US nl-BE
short 10/23/26 23/10/2026
medium Oct 23, 2026 23 okt 2026
long (default) October 23, 2026 23 oktober 2026
full Friday, October 23, 2026 vrijdag 23 oktober 2026

Range

Section titled “Range”

For a range, give the date picker two date inputs as content, the start and then the end, and an aria-label that names the range. The popover closes after the second pick. The button shows both ends: Oct 12, 2026 – Oct 21, 2026 with format="medium" (the separator is the message sl.date-picker.range, see Translating).

Date of birth

Section titled “Date of birth”

The calendar’s month and year selects (caption-layout="dropdown") help with dates far from today.

In a form

Section titled “In a form”
  • The label. In a field, the label points at the date input inside the popover, as for a calendar. The button takes the label’s text and the date it shows as its name (“Pickup date, October 23, 2026”), and a click on the label focuses the button.
  • Errors. A field with errors marks the input and the button aria-invalid="true", and the field’s error describes both.
  • Validation. The browser can only point at a control it can show. When a required date is empty on submit, the popover opens, so the browser’s message points at the calendar.
  • Events. A pick fires input and change on the input, as on a calendar.
  • A value set by a script shows on the button once the script fires change on the input.
  • Form reset puts the button’s text back too.

Disabled

Section titled “Disabled”

disabled on the input, or on a <sl:field-set> around it, disables the button.

Keyboard

Section titled “Keyboard”
Key On Does
Enter, Space The button Opens the popover, with the focus on the chosen day, or else today
Arrows, Home, End, Page Up, Page Down A day Move the focus, as in the calendar
Enter, Space A day Picks it, and closes the popover once the date (or both ends of the range) is chosen
Escape The popover Closes it, and the focus goes back to the button
Tab The popover’s last stop Closes it, as the focus leaves it

The popover is a non-modal dialog, as sl:popover is. The focus is not trapped in it.

With htmx

Section titled “With htmx”
  • Back restores the date picker as htmx saved it, and slDatePicker formats the date again.
  • hx-trigger="change" on the date picker’s input (<sl:date-picker hx-post="..." hx-trigger="change">) or on the form sends the picked date.

Left out

Section titled “Left out”
  • An input to type the date into, the time and natural language variants are not here yet. For a time, put an <sl:input type="time"> next to the date picker.
  • Presets (a select of “Today”, “Tomorrow”, …) are not here either.

Attributes

Section titled “Attributes”
AttributeValuesDefaultDescription
placeholderstring—The button's text while no date is chosen. By default "Pick a date".
formatshort medium long fulllongHow the button shows the date, in the page's locale: as Intl.DateTimeFormat's dateStyle and Java's FormatStyle (10/23/26, Oct 23, 2026, October 23, 2026, Friday, October 23, 2026).
popover-idstring—The popover's id, which the button points at with popovertarget. By default a generated one (sl-date-picker- and eight random characters).

Every prop can also be set from an expression: th:placeholder="${...}". Any other attribute passes through to the rendered element, and class is appended.

JavaScript

Section titled “JavaScript”

slDatePicker sits on the date picker: <div class="date-picker" x-data="slDatePicker">. Its popover has slPopover and its calendar slCalendar.

  • It needs JavaScript. Without Alpine, the button still opens the popover (popovertarget), but it holds the bare date inputs, and the button’s text does not follow them.
  • It needs no Alpine plugin. If you load Alpine yourself (shadleaf.assets.alpine=external), plain Alpine is enough.
  • Keep your own x-data off <sl:date-picker>: an element has one x-data. Listen for change on the input instead.
