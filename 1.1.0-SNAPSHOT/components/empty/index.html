Empty

Built from parts

Section titled “Built from parts”

An empty state is <sl:empty> plus the parts you need, as in shadcn/ui: <sl:empty-header> (holding <sl:empty-media>, <sl:empty-title> and <sl:empty-description>) and <sl:empty-content> for what to do next, such as a button, a search field or a link. Everything is centred, and the empty state grows to fill a flex container, so it sits in the middle of the space it is given.

<sl:empty-media variant="icon"> puts an icon on a muted square. The default media shows its content as it is, for an avatar or an image.

A title that is a heading

Section titled “A title that is a heading”

<sl:empty-title> is plain text unless you give it a level. With one, it is announced as a heading of that level. Pick the level that fits the page: an empty state under an <h2> gets level="3".

Outline

Section titled “Outline”

border draws a dashed line around the empty state, to mark out the area. It works without utility classes, so also with the standalone stylesheet.

In a card

In an empty table

Section titled “In an empty table”

Put the empty state in <sl:table-empty>, which spans every column: it replaces the row’s “No results.” text.

With a search field

Section titled “With a search field”

A link in a description is underlined. An <sl:empty-description> can also go in the content, below the field.

While it loads

Section titled “While it loads”

An <sl:spinner> takes the icon’s place in the media while something loads.

Attributes

Section titled “Attributes”

sl:empty

Section titled “sl:empty”
AttributeValuesDefaultDescription
borderboolean—A dashed line around the empty state, to mark out the area (shadcn's border border-dashed classes).

Every prop can also be set from an expression: th:border="${...}". Any other attribute passes through to the rendered element, and class is appended.

sl:empty-header

Section titled “sl:empty-header”

sl:empty-header declares no props; every attribute passes through.

sl:empty-media

Section titled “sl:empty-media”
AttributeValuesDefaultDescription
variantdefault icondefaulticon puts an icon on a muted square; default shows the content as it is, e.g. an avatar.

Every prop can also be set from an expression: th:variant="${...}". Any other attribute passes through to the rendered element, and class is appended.

sl:empty-title

Section titled “sl:empty-title”
AttributeValuesDefaultDescription
level1 2 3 4 5 6—Heading level. With it the title is a heading (role="heading" and aria-level) that screen reader users can jump to; without it, plain text. Pick the level that fits the page's outline.

Every prop can also be set from an expression: th:level="${...}". Any other attribute passes through to the rendered element, and class is appended.

sl:empty-description

Section titled “sl:empty-description”

sl:empty-description declares no props; every attribute passes through.

sl:empty-content

Section titled “sl:empty-content”

sl:empty-content declares no props; every attribute passes through.
