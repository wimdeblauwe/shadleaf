Button

A button never submits by accident

Section titled “A button never submits by accident”

<sl:button> renders type="button", not HTML’s default submit. A button inside a form therefore does nothing unless you say so: write type="submit" on the one that should submit.

Variants

Section titled “Variants”

Sizes

Section titled “Sizes”

The icon sizes are square, for a button holding only an icon. Such a button has no text for a screen reader, so it must have an aria-label (or aria-labelledby); rendering fails without one.

With an icon

Section titled “With an icon”

Put an <sl:icon> in the icon-start or icon-end slot. It takes the button’s colour and a 16 pixel size.

As a link

Section titled “As a link”

as="a" renders an anchor that looks the same, for navigation.

Disabled and loading

Section titled “Disabled and loading”

A disabled button gets the native disabled attribute. A disabled link loses its href, leaves the tab order and is marked aria-disabled, so it cannot be followed. loading shows a spinner in place of the start icon, announces the busy state with aria-busy and a visually hidden “Loading” label, and disables the button.

The “Loading” label comes from the message sl.button.loading; define it in your own messages.properties to translate or reword it.

Props from expressions

Section titled “Props from expressions”

Every prop also has a th: form that takes a Thymeleaf expression.

Everything else passes through

Section titled “Everything else passes through”

Attributes that are not props, such as hx-*, x-*, aria-* and data-*, land on the rendered element unchanged, so the button works with htmx and Alpine. class is appended to the component’s own class.

Attributes

Section titled “Attributes”
AttributeValuesDefaultDescription
variantdefault outline ghost destructive secondary linkdefaultVisual style of the button.
sizexs sm default lg icon icon-xs icon-sm icon-lgdefaultSize of the button. The icon sizes are square, for a button that holds only an icon, and need an aria-label.
asbutton abuttonElement to render: a button, or an anchor (a) for navigation.
typebutton submit resetbuttonSubmit behaviour. Defaults to button, unlike HTML, so a button in a form never submits by accident.
disabledboolean—Disable the button. A disabled anchor loses its href and leaves the tab order.
loadingboolean—Show a spinner, announce the busy state and disable the button.

Every prop can also be set from an expression: th:variant="${...}". Any other attribute passes through to the rendered element, and class is appended. An aria-label or aria-labelledby is required when size is icon, icon-xs, icon-sm or icon-lg; rendering fails without one.
