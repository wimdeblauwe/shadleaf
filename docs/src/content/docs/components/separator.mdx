A thin horizontal or vertical line between pieces of content.

<ComponentPreview id="separator--default" />

## When to use

- Between the sections of a page, a card or a panel.
- Between groups of buttons or links in a toolbar or a header (vertical).

Use something else for:

- Between the items of a list: the [item separator](../item/#group).
- Between the groups of a menu or a select: the separator part of that component.

## Vertical

`orientation="vertical"` draws a vertical line that stretches to the height of the row it is in. Put it in a flex
container, such as a toolbar or a row of links.

<ComponentPreview id="separator--vertical" />

## Decorative or announced

A separator is decorative by default: it only draws a line and is hidden from assistive technology
(`role="none"`). When the line divides the content into groups a screen reader user should know about, write
`decorative="false"`. It is then announced as a separator (`role="separator"`, with `aria-orientation` when
vertical).
