A small, rounded label next to other content, in the same variants as the button.

<ComponentPreview id="badge--default" />

## When to use

- The state of something in a table row, such as Paid, Pending or Failed.
- A count, such as unread messages.
- A tag or a category on an item or a card.

Use something else for:

- A count next to a link in the sidebar: the sidebar's [menu badge](../sidebar/#badges).
- A key on the keyboard: a [kbd](../kbd/).
- A message the user should read: an [alert](../alert/).

## Variants

The same variants as the [button](../button/).

<ComponentPreview id="badge--variants" />

## With an icon

Put an [`<sl:icon>`](../icon/) in the `icon-start` or `icon-end` slot. It takes the badge's colour and a 12 pixel size.

<ComponentPreview id="badge--with-icon" />

## As a link

`as="a"` renders an anchor, for a badge that filters a list or opens a detail page. Only a linked badge reacts to hover
and shows a focus ring; a plain badge is not interactive, so it does not pretend to be.

<ComponentPreview id="badge--link" />

A badge is text, so a screen reader reads it where it stands. When a bare number or a single word would not make sense
out of context, write the context into the text, or next to the badge.
