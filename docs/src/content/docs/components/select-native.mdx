The browser's `<select>`, with the closed control in the skin's look and the list left to the operating system, which on
a phone is its own picker.

<ComponentPreview id="native-select--default" />

## When to use

- Long lists, such as countries or years.
- Dense forms and filter bars.
- Several values at once (`multiple`).

Use something else for:

- A list drawn in the page's style, with icons and a check mark: a [select](../select/).
- A list the user searches: a [combobox](../combobox/).

## Native select or select?

Both are a real `<select>` underneath, bind with `th:field` and submit with the form. This one styles only the closed
control and leaves the list to the operating system: on a phone that is the system's own picker, which many people find
easier to use. Use it for long lists (countries, years), in dense forms, and for `multiple`. [`<sl:select>`](../select/)
draws its list in the page's style, with a check mark on the chosen item and room for an icon; use it where the look
matters and the list is short enough to scan.

## Options

Write plain `<option>` and `<optgroup>` elements as the content, with `th:each` for options from the model. With
`th:field` on the select, Spring marks the option that matches the field's value as selected.

<ComponentPreview id="native-select--groups" />

## Sizes

<ComponentPreview id="native-select--sizes" />

`size` picks the height. It replaces HTML's own `size` attribute, which turns a select into a list box;
`multiple` still works, and hides the chevron.

## Width

The select sits in a wrapper that also holds the chevron. `class` goes to that wrapper, so `class="w-full"` widens
both; every other attribute goes to the `<select>`.

## Invalid

As with the [input](../input/), a field with errors marks the select `aria-invalid="true"`.

<ComponentPreview id="native-select--invalid" />

## Disabled

The select fades with its chevron; the lyra and nova skins also give it a grey background, as they do a disabled input.
HTML has no read-only select: `readonly` does nothing on one. To show a choice that cannot be changed, use a read-only
[input](../input/#read-only) with the option's text, and a hidden input if the value has to be submitted.
