[Penguin UI](https://www.penguinui.com) is a free (MIT) collection of components built with Tailwind CSS v4 and
Alpine.js. There is nothing to install beyond those two: you copy a component's markup into your template and change
it as you like.

## The same dialog

```html
<!-- Penguin UI, utility classes shortened -->
<div x-data="{modalIsOpen: false}">
  <button x-on:click="modalIsOpen = true" type="button" class="...">Edit profile</button>
  <div x-cloak x-show="modalIsOpen" x-trap.inert.noscroll="modalIsOpen"
       x-on:keydown.esc.window="modalIsOpen = false" x-on:click.self="modalIsOpen = false"
       class="fixed inset-0 z-30 ..." role="dialog" aria-modal="true" aria-labelledby="edit-profile-title">
    <div x-show="modalIsOpen" class="...">
      <h3 id="edit-profile-title" class="...">Edit profile</h3>
      ...
      <button x-on:click="modalIsOpen = false" type="button" class="...">Save</button>
    </div>
  </div>
</div>
```

```html
<!-- Shadleaf -->
<sl:button commandfor="edit-profile" command="show-modal">Edit profile</sl:button>
<sl:dialog id="edit-profile">
  <sl:dialog-header>
    <sl:dialog-title>Edit profile</sl:dialog-title>
  </sl:dialog-header>
  ...
  <sl:dialog-footer>
    <sl:button type="submit">Save</sl:button>
  </sl:dialog-footer>
</sl:dialog>
```

The behaviour is right there in the markup, as Alpine.js expressions: visible and easy to change.

## Where Penguin UI is stronger

- **You own the markup.** No dependency to upgrade and no engine to learn.
- **Any stack** that can load Tailwind and Alpine.js, Spring included.
- **A theme designer** with distinct presets (Arctic, Minimal, Neo Brutalism, Pastel and more), dark mode included.
- **Some components Shadleaf has not**: a carousel, chat bubbles, a rating, a counter, steps, and components for AI
  chat interfaces.

## Where Shadleaf is stronger

- **No Tailwind build.** Penguin UI needs Tailwind CSS v4 in your build; Shadleaf's jar ships its CSS.
- **Without JavaScript.** Penguin UI's modals, dropdowns and tabs keep their state in Alpine.js and do not open
  without it. Shadleaf's are native elements first (`<dialog>`, popovers, `<details>`) that work with Alpine.js
  missing.
- **More components.** Penguin UI has no date picker or calendar, no chart, no sheet or popover, and its table is
  styling only.
- **Components instead of markup**, with declared props and one place to change. See
  [what a component engine adds](../#what-a-component-engine-adds).
- **Spring wiring, a documented strict CSP, and tested accessibility**: `th:field` binding and errors, Spring Data
  paging, a [CSP guide](../../guides/csp/), axe on every example.

## Which one to choose

**Choose Penguin UI** if you already compile Tailwind and use Alpine.js, want a look of your own, and are happy to
own and maintain the markup. **Choose Shadleaf** for Thymeleaf components with the Spring wiring done.
