Card

Built from parts

Section titled “Built from parts”

A card is <sl:card> plus the parts you need, as in shadcn/ui: <sl:card-header> (holding <sl:card-title>, <sl:card-description> and <sl:card-action>), <sl:card-content> and <sl:card-footer>. Use any of them, in any order. Each part is its own component, so it has its own attributes and IDE completion, and passes every other attribute through.

A card takes the width of its container; set it from your layout.

A title that is a heading

Section titled “A title that is a heading”

<sl:card-title> is plain text unless you give it a level. With one, it is announced as a heading of that level, so screen reader users can jump between cards. Pick the level that fits the page: a card under an <h2> gets level="3".

Small

Section titled “Small”

size="sm" tightens the spacing inside the card and between its parts.

Dividing lines

Section titled “Dividing lines”

border on the header or the footer draws a line between it and the content, with matching spacing. It works without utility classes, so also with the standalone stylesheet.

sl:card-header

Section titled “sl:card-header”
AttributeValuesDefaultDescription
borderboolean—A dividing line below the header, with matching spacing.

Every prop can also be set from an expression: th:border="${...}". Any other attribute passes through to the rendered element, and class is appended.

sl:card-title

Section titled “sl:card-title”
AttributeValuesDefaultDescription
level1 2 3 4 5 6—Heading level. With it the title is a heading (role="heading" and aria-level) that screen reader users can jump to; without it, plain text. Pick the level that fits the page's outline.

Every prop can also be set from an expression: th:level="${...}". Any other attribute passes through to the rendered element, and class is appended.
