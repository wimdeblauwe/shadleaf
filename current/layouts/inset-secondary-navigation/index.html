Inset with secondary navigation

A sidebar whose sections are pages of their own: the section’s name is a link, and a chevron beside it opens and closes its pages in a collapsible sub-menu. The server opens the current page’s section. Below them the projects, each with a “More” menu, and at the bottom of the content a secondary navigation (Support, Feedback) in small buttons. The footer holds the user menu. The page is a card beside the sidebar (variant="inset"), and its header has the trigger, the breadcrumb and the theme toggle. On a desktop the trigger moves the sidebar out of view; on a phone it opens the same sidebar as a panel. Switch the preview to Phone to see it.

For reference: the shadcn/ui block this layout is based on.

The layout

Section titled “The layout”

The whole layout file. It has what every layout needs: the theme script and Shadleaf’s assets in the head, the skip link first, one main (<sl:sidebar-inset>), the page’s title, and the toaster. The chevrons are summary elements and need a name each (aria-label), as an icon button does: “Playground’s pages”.

A page

Section titled “A page”

A page passes its title, its breadcrumb’s levels and its content. The levels are a th:block with th:ref, so nothing of it is rendered where it stands; the layout puts them in its <sl:breadcrumb-list>.

The CSS

Section titled “The CSS”

Shadleaf’s CSS styles the components, not the page around them, and has no utility classes. The rest is the application’s CSS, here without Tailwind: the square behind the logo, the secondary navigation pushed to the bottom of the content (the nav-secondary class on its group), and the page’s padding.
